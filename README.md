# Create: Physics Gun

A Half-Life 2 style physics gun for Create physics worlds.

This mod adds the **Zero-Point Physics Gun**, a gravity-gun inspired tool for grabbing, pulling, moving, and punting physics objects from Sable and Simulated.

## Features

- Grab and carry Sable sub-level physics objects
- Grab and punt pickable entities
- Orange beam while holding a target
- Animated physics gun model while grabbing
- Scroll wheel hold-distance adjustment
- Faithful physics-gun behavior based on Valve's Source SDK 2013

## Controls

- Right click: grab or release
- Left click: punt
- Scroll: move held object closer or farther

## Requirements

- Minecraft 1.21.1
- NeoForge
- Create
- Create: Aeronautics
- Sable
- Simulated

## Notes

This is meant to feel close to the Half-Life 2 physics gun while working with Minecraft physics objects.

Source SDK 2013 reference:
https://github.com/ValveSoftware/source-sdk-2013

The model and visuals are based on Simulated's physics staff style, recolored and adapted for this item.
